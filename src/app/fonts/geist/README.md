Geist Sans and Geist Mono WOFF2 subsets are local, unmodified font assets cached by Next.js from the official Google Fonts distribution. The corresponding font CSS identifies the families as Geist and Geist Mono and assigns the subset unicode ranges retained in src/app/globals.css.
